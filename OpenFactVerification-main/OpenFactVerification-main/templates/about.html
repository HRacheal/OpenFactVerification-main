How Kweli Lens AI works

  1. Read the input. Text is used as-is. Links are fetched safely and the article text extracted. Images are read by an AI vision model; audio is transcribed; videos are sampled (a few frames plus the audio track).
  2. Extract claims. An AI model lists the distinct factual statements, keeping the original language, numbers, dates and qualifiers.
  3. Decide what can be checked. Opinions, predictions and vague statements are marked "Not checkable".
  4. Search for evidence. Web searches (Google via Serper) are run in the claim's language and English, biased toward the selected country. Each result page is read where possible.
  5. Assess each piece of evidence. The AI labels each excerpt as supporting, contradicting, partly supporting, context, or not relevant, using only that excerpt, and must quote the exact passage it relied on. Quotes are checked against the source text; an unverifiable quote downgrades the judgement to "inferred".
  6. Apply fixed verdict rules (below). The AI does not choose the verdict.

Verdict rules

✔ Supported
Reliable, independent evidence supports the claim and no comparable evidence contradicts it.
✖ Contradicted
Reliable, independent evidence directly conflicts with the claim and no comparable evidence supports it.
◐ Mixed / conflicting
The claim is only partly right, or credible sources disagree.
? Insufficient evidence
Not enough strong evidence was found to conclude either way. This never means "false".

How evidence is weighted

Only evidence that supports, contradicts or partly supports the claim counts. Each piece gets a weight:

  • Basis: explicitly stated with a verified quote = {{ basis_weight.explicit }}, inferred = {{ basis_weight.inferred }}
  • Source type (from the domain only): government/intergovernmental, academic and fact-checkers = {{ source_weight.official }}; news outlets = {{ source_weight.news }}; other websites = {{ source_weight.unknown }}; social media = {{ source_weight.social }}
  • Search snippet only (page could not be read): × {{ snippet_weight }}

Pages from the same website count as one source. A side is established when its total weight reaches 1.0 (e.g. one explicit official statement, or two explicit statements from different news outlets). If both sides are established, or the stronger side is less than twice the weaker, the verdict is Mixed. If neither side is established, the verdict is Insufficient evidence.

Evidence strength (low / moderate / high) reflects how much weighted evidence backs the verdict (below 1.5, 1.5-3, 3 and above). It is not a probability that the claim is true.

Source types are a rough hint based on the website address. A source on a preferred list can still be wrong; always open and judge the sources yourself.

Known limitations

  • Search results depend on what is indexed online; local-language and offline sources are under-represented.
  • Luganda support is experimental: AI models and search engines have limited Luganda coverage, so claim extraction, transcription and explanations may contain errors. Swahili is better supported but still machine-generated.
  • Pages behind paywalls, logins or heavy JavaScript cannot be read; the snippet is used instead and flagged.
  • Video analysis samples a few frames; brief on-screen text can be missed. Only the first 10 minutes are analysed.
  • Text read from images and audio transcripts may contain errors. They describe what the media says, not whether it is true.
